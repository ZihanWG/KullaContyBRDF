# Asset provenance

This inventory records the origin and release status of non-code assets. It is
part of the release gate: an asset marked **confirmation required** must not be
treated as cleared for redistribution until the repository owner records the
source and applicable license.

| Repository path | Origin | Release status |
| --- | --- | --- |
| `Content/LearningLabs/**` | Generated for this project by `Tools/Unreal/CreateRenderingLearningLabs.py` using Unreal basic shapes and project-created materials | Project generated; retain script as provenance |
| `Content/LUTS/**` | Imported from LUTs generated by this project's CPU tool | Project generated |
| `roughness_row.png`, `cornell_box.png` | Presentation captures produced from the project | Project output |
| `Content/Assets/**` | Early prototype materials created during the project | Owner confirmation required |
| `Content/Main.umap`, `Content/RowCompareTest.umap` | Early project evaluation maps | Owner confirmation required |
| `Content/testScene.fbx`, `Content/testScene.umap`, `Content/CornellBoxTest.umap` | README previously attributes the original Cornell-box source to a Parametric Cornell Box asset from Fab | Source listing and redistribution permission must be confirmed; replace or remove if source redistribution is not permitted |
| `Content/BlankDefault/**` | Unreal editor-created blank level and thumbnail | Confirm that no restricted third-party content is embedded |

## Owner sign-off required

Before creating a public release tag:

1. Record the exact Fab listing or original source for the Cornell-box files.
2. Verify whether source `.fbx`, `.umap` and derived `.uasset` redistribution is
   permitted under the acquired license.
3. Confirm that every file in `Content/Assets` was authored for this project or
   replace it with a reproducible project-generated equivalent.
4. Remove any asset that cannot be documented.
